# 徳を積め！

「徳」の字（金色の立体文字）だけを積み上げて、高層ビル → 東京タワー → スカイツリー → 富士山 → 成層圏 → 月 …… を目指す縦型ミニWebゲーム。

## 遊び方

- 画面上で左右に揺れている「徳」を **タップ（またはスペースキー）** で落とす。
- 引っかけの「**得**」「**特**」は **見送る**。しばらく待つと飛んでいく。積んだらゲームオーバー。
- 「得」「特」は11個目から出る。出たあとは必ず「徳」が出る（2回続けては出ない）。出る率は何個目の字かで決まる（`CONFIG.fakeRates`）：

  | 何個目 | 1〜10 | 11〜20 | 21〜30 | 31〜40 | 41〜50 | 51〜 |
  |---|---|---|---|---|---|---|
  | 得・特の率 | 出ない | 10% | 15% | 20% | 25% | 30% |

  率は「直前が徳だったとき」に得・特を出す確率。直後は必ず徳なので、全体に占める割合はこれより少し低い（30%のとき約23%）。
- 揺れは積むほど速くなり、60個目あたりで頭打ちになる。61個目からは10個ごとに1段（8%）ずつ速くなり、「揺れが速くなった！」と表示する（61個目で約8%、71個目で約16%、100個目で約32%速い）。
- 塔の重心が下の段からはみ出すと **崩れる**。片側に寄ったら反対側で取り返す。
- 崩れるかどうかは段ごとに決まる。その段より上にある字の重心（横位置の平均）が、その段の字の中心から 46px（字の半幅 40px × `stickiness` 1.15）を超えると、そこから上が崩れる。一番下の段は土台の中心から 126px まで耐える。
- 片側に寄るほど塔が **傾いて見える**（見た目だけで、判定は変わらない）。段ごとの「重心のずれ ÷ 限界」を下から足し合わせた角度で各字を回す。左右で取り返すと傾きも戻る。置いた瞬間は、ばねのように少し揺れてから落ち着く（`leanTargets`）。
- 真上に近い位置（10px 以内）に落とすと「ぴったり」になり、真上にそろう。
- 終了時、積めた徳の数に応じて **称号** がもらえる（名所とは別に決まる。`TITLES`）。最高記録はブラウザに保存する。

  | 積んだ数 | 0〜10 | 11〜20 | 21〜30 | 31〜40 | 41〜50 | 51〜60 | 61〜70 | 71〜80 | 81〜90 | 91〜99 | 100〜 |
  |---|---|---|---|---|---|---|---|---|---|---|---|
  | 称号 | 極悪人 | 煩悩の塊 | 普通の人 | ちょっといい人 | 普通にいい人 | 善人 | 修行僧並 | 住職並 | 高僧並 | 聖人君子 | ブッダ |

- 称号の表（何個で何の称号か）はゲーム内では見せない。結果画面には今の称号だけを1行で出し（長い称号は字を小さくする）、次の称号や名所までの残りは出さない。
- 積んでいる途中で称号が上がると「称号『普通の人』に昇格！」と出す。名所を越えた瞬間と重なったときは、名所のバナーの下の行で知らせる。名所のバナーにはそのときの称号を出す。

## 名所の見せ方

- 画面に出すのは「直前にクリアした名所」と「次の目標」だけ。
- 次の目標は、まだ遠いうちは画面の上の方に霞んで見え、近づくほどはっきりする。届く高さが画面に入ると、その高さに金色の「目標ライン」を引く。名所の頂上は、届く高さ（n 個目の上端）にそろう。
- 家・大仏・五重塔・高層ビル・東京タワー・スカイツリーは、絵の高さを「地面から届く高さまで」にして、必ず地面に建つようにしている（`grounded`）。家と大仏は比率を保って拡大し、ほかは高さに合わせて形を描く。
- 越えた瞬間に名所が金色に光り、次の目標がふわっと現れる。上部の表示は「次の目標：東京タワー（333 m）あと3徳」。
- 名所の絵は Canvas で描き込み（グラデーション・陰影・鉄骨の格子・窓・雪の筋・クレーターなど）、最初に一度だけ画像にして使い回す（`LANDMARKS`／`sprite`）。旅客機・成層圏・宇宙の果ては動きがあるのでその場で描く（`drawLiveLandmark`）。ビル・東京タワー・スカイツリーの先端では航空障害灯が点滅する。
- `npm run shots:landmarks` で、名所ごとに「遠い」「近い」「越えた直後」の画面を `shots/lm-*.png` に撮る。

## 崩れたときの見せ方

- 「得」「特」を積んだときは、すぐには崩さず、約1.9秒かけて間違いを見せる（`fakeShowTime`／`drawFakeFx`）。
  1. 周りを暗くし、積んだ字だけを赤く光らせて脈打たせる。
  2. 0.35秒後に、ハンコを押すようにばつ印を重ねる（字が読めるよう半透明）。
  3. 上に「『得』は徳じゃない！　得 ≠ 徳」のカードを出す。
  4. 最後の0.6秒で塔が震え、そのあと崩れてカメラを引く。

- 終わった瞬間にカメラを一気に引いて、地面から塔の頂上までを画面に収める（`S.view`／`updateView`／`viewTransform`）。
- 崩れた徳は、高い段ほど遠くへ倒れながら落ちる。地面で跳ねてから、寝た向きか立った向きで止まる。先に落ちた徳の上にも2段くらいまで乗る（`updateDebris`）。
- カメラは散らばった範囲の真ん中に合わせ、全部が入るまでさらに引く。散らばり終えたら、残った塔と地面の徳の山に少し寄る。
- 全部止まってから約1秒後に結果を出す（最長7秒）。結果画面は文字を上にまとめ、下の方で地面に散らばった徳が見えるようにしている。
- 引いている間は、空の色を塔の高さまでの色にとどめ、雲を薄くする。名所は、地面に建つもの（家〜スカイツリー）だけを塔の横に実際の大きさで出す。

## 名所と高さ

n 個積むとその名所の高さに届く（`MILESTONES`／`ALT_TABLE`／`altitudeAt`）。

- 名所の間は、1個あたりの伸びが前の字より小さくならないようにつなぐ。名所の位置での伸びを「左右の区間の平均の伸び」の相乗平均にし、区間の中ではその間を単調に変化させ、合計が名所の高さの差に合うよう形を調整する。
- 大仏（8個）までは1個あたり同じ 1.875 m。そのため家は 7.5 m にしている（表示は 8 m）。
- 例外はエベレスト（42個）→旅客機（46個）の区間。この区間は平均の伸び（約290 m）が前の区間（約720 m）より小さいので、43個目で伸びが小さくなる。

- 名所を越えた瞬間と揺れが速くなる瞬間（80・90・100…個目）が重なったときは、「揺れがさらに速く！」を名所のバナーの下に出す。長い名所の名前は、バナーに収まるよう文字を小さくする。

## 調整値

`game.js` 冒頭の `CONFIG` にまとめている。主なもの：

- `swingBase` / `swingPerBlock` / `swingMax`：揺れの速さ（積むほど速くなり、`swingMax` で頭打ち）
- `swingStepFrom` / `swingStepEvery` / `swingStepRate`：61個目から10個ごとに速くする段階と、1段階で速くなる割合
- `fakeRates`：何個目から得・特が出るかと、その率
- `perfect`：「ぴったり」の判定幅
- `stickiness`：崩れにくさ（重心のずれが支えの半幅の何倍まで耐えるか）
- `fakeShowTime`：得・特を積んだとき、崩れる前に強調して見せる秒数
- `leanPerLevel` / `leanMax`：塔の傾きの大きさ（限界ちょうどずれた段1つで傾く角度）と上限
- `collapseSpread` / `spreadMax`：崩れた徳が横へ散らばる強さと、その上限
- `pullBackTime` / `pullTopY` / `pullGroundY`：カメラを引く速さと、引いたときの塔の頂上・地面の画面上の位置
- `resultAfterSettle` / `resultMax`：散らばり終えてから結果を出すまでの秒数と、最長の秒数

### 難しさの目安（シミュレーション）

狙った位置からの誤差（標準偏差）ごとの到達個数（中央値 / 上位10%）。片寄りを反対側で取り返す狙い方の場合：

- 誤差 ±10px：120個以上 / 120個以上
- 誤差 ±15px：29個 / 82個
- 誤差 ±22px：7個 / 20個

揺れが速くなる分は含めていないので、実際はこれより少し難しい。
（この数字は、得・特の出し方を変える前の設定で測ったもの。）

## 開発

```sh
npm install        # 確認用の playwright-core のみ
npm run dev        # http://localhost:5173/
npm run check      # 構文チェック
npm run e2e        # ヘッドレス Chrome で通しの確認（shots/ に画面を保存）
npm run shots:landmarks   # 名所ごとの見え方を撮る（名前を指定すると絞れる: -- fuji,moon）
npm run favicon    # favicon を作り直す（public/favicon.png と favicon.svg）
npm run ogp        # OGP 画像を作り直す（public/ogp.png）
npm run build      # 公開用ファイルを dist/toku/ に書き出す
npm run deploy     # ビルドして Cloudflare に公開
```

- 依存なしの HTML / CSS / JavaScript（Canvas）。
- `public/` のファイル（favicon）は、開発サーバーでルートのパスとして返す。
- favicon はプレイ中と同じ立体の「徳」で、背景は透過。`npm run favicon` で、ゲームの字の描き方（`glyphSprites` と `drawBlock` と同じ重ね方）から `public/favicon.png`（192×192）と、それを埋め込んだ `public/favicon.svg` を書き出す。字の見た目を変えたら作り直す。
- OGP 画像は `public/ogp.png`（1200×630）。左にタイトル・副題・遊び方・URL（game.chozo.net/toku）、右にゲーム画面（東京タワーの手前で「特」が揺れている場面）を置く。`npm run ogp` で、ゲームを確認用の入口で進めて撮り、HTML に重ねて書き出す（乱数を固定しているので毎回同じ絵になる）。favicon の画像をロゴの「徳」に使うので、favicon を作り直したら OGP も作り直す。
- 公開URLは `https://game.chozo.net/toku/`。`index.html` の `og:url` と `og:image` はこの URL の絶対パスにしている。
- 確認用の入口 `window.__game`：`state()`、`start()`、`drop()`、`manual(true)` と `step(dt, n)`（1コマずつ進める）、`forceNext('fake' | 'toku')`、`buildTower(n)`、`setSeed(n)`、`drainEvents()`、`fakeRate(k)`／`swingSpeed(k)`（k 個目の率と速さ）、`sampleKinds(n, count)`（次の字の選ばれ方を調べる）。`state()` は引いたカメラの倍率（`zoom`）と、崩れた徳の数・止まった数（`debris` / `settled`）も返す。

## 素材

- 画像はすべて Canvas で描いている（立体文字、名所、空、星）。画像ファイルは使っていない。
- 立体文字：字の正面・側面・縁を画像にしておき、側面を奥へずらして10層重ねて厚みを出す（`glyphSprites`／`drawBlock`）。字は当たり判定の箱（`BW`×`BH`）にぴったり収まるよう伸縮し、揺れ・落下・崩壊時は縦軸まわりに回る。ニセモノも同じ見た目。積んでしまった「得」「特」だけ赤くなる。
- 音は Web Audio API で合成（木魚＝積む、おりん＝ぴったり、ファンファーレ＝名所超え、ブザー＝得特、崩壊音）。最初のタップ後に鳴る。
- フォント：Google Fonts の Dela Gothic One（立体文字）、Yuji Syuku、Zen Maru Gothic（いずれも SIL Open Font License）。読み込めない場合は端末のゴシック体・明朝体で表示する。

- URL：https://game.chozo.net/toku/
